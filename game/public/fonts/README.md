# Fonts

`fredoka-700-latin.woff2` — Fredoka Bold (700), Latin subset, from the
`@fontsource/fredoka@5.0.8` package. Used for all native game text: the title
logo, "GO!" on the Go! wipe and the "Nom Nom!" bubble. Fredoka is licensed
under the SIL Open Font License 1.1 (https://openfontlicense.org). Source:
Google Fonts (https://fonts.google.com/specimen/Fredoka).
